# Showcraft for Claude Code

The plugin brings [Showcraft](https://getshowcraft.com)'s MCP server into Claude Code and the `/showcraft:drive` command, the loop that answers the app's red button and chat while you work in it.

```
/plugin marketplace add olivier-babelcast/showcraft-plugin
/plugin install showcraft@showcraft
/mcp
```

Then pick `showcraft` and Authenticate: the browser opens Showcraft's sign-in page. The server is gated: a Showcraft account that we have let in is needed to sign in. In a session, `/showcraft:drive`, or say "drive Showcraft".

Step by step, with screenshots, for Claude, Claude Code, Codex and ChatGPT: https://getshowcraft.com/app/connect.html
